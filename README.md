把《李大霄投资战略》第三版做成了一个可直接在浏览器里翻阅的网页阅读器，无需下载、无需插件，手机和电脑都能看。

## 在线阅读

https://dd2026578.github.io/lidaxiao-investment-strategy/

## 阅读器功能

- **逐页浏览**：鼠标点左右两侧、`←` `→` 方向键、手机左右滑动都可翻页
- **目录跳转**：点顶部「目录」，116 条原书章节可直接跳转，当前章节自动高亮
- **快速定位**：底部进度条拖动，或输入页码回车直达
- **显示模式**：`Z` 或双击页面，在「整页」与「适应宽度」之间切换
- **夜间模式**：`D` 切换，纸面反色为深色背景，夜里看不刺眼
- **全屏阅读**：`F` 进入全屏，`Esc` 退出
- **记忆进度**：下次打开自动回到上次读到的那一页；链接带 `#p=页码` 可直接分享位置
- **预加载**：自动预读相邻页面，翻页基本无等待
